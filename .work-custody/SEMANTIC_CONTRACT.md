# Semantic Contract
## Success Criteria
All identified repo inconsistencies resolved: MDX integration working, /story/ route functional, event data verified, build process confirmed.

## Acceptance Criteria
- [x] Blog posts converted from .md to .mdx
- [x] @astrojs/mdx installed and configured in astro.config.mjs
- [x] /story/ route created and rendering content
- [x] npm run lint passes with 0 errors
- [x] Event confidence values verified (no "unverified" events found)
- [x] Build process confirmed to handle data generation (prebuild script)

## Out of Scope
- Creating new blog content (thin blog content is a separate task)
- Modifying existing blog post content
- Changing archive pages
