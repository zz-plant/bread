This page is the working event list for BREAD. It uses clear row-by-row fields so each entry can be tracked and updated over time.


## Field schema

- **Date**: ISO when known, otherwise period marker.
- **Series**: event number or special format.
- **Venue/platform**: physical venue or stream platform.
- **Lineup highlights**: short, non-exhaustive roster.
- **Source basis**: where this row currently comes from.
- **Source notes**: `published`, `strong`, `user-archive`, or `open`.
